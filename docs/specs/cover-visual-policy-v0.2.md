# 封面视觉规范 v0.2

## 目标

封面是默认视频 v5 的主视觉，也是用户作品在社区展示、播放和分享时的第一眼信号。当前策略是让 Image2 直接生成完整 16:9 单曲封面，并允许封面内出现作品歌名。

## 文字策略

封面允许出现文字，但只允许出现一个受控文本元素：

- 作品歌名，来源必须是当前作品 `song_title`。

封面禁止出现：

- 假歌手名、假演唱者、假制作人、假作词、假作曲。
- 假厂牌、假版权、`label`、`copyright`、`feat`、版权符号。
- 随机英文小字、宣传口号、长副标题、排行榜、二维码、UI、水印。
- 乱码、伪汉字、不可读文字。

当前阶段不接 OCR，也不设置人工确认位。质量门只审核 prompt 层面的约束：是否只允许作品歌名，是否禁止额外署名和水印等风险文字。

## 画面策略

默认封面必须：

- 固定 16:9，推荐 `2048x1152`，最低不低于 `1920x1080`。
- 像正式音乐单曲封面，而不是活动海报、游戏截图、PPT 背景或廉价网游图。
- 有清晰视觉焦点，移动端小尺寸下仍能识别。
- 具备《燕云十六声》气质：江湖、乱世、边地、寻声、武学、同行、家国、风雪、灯火等抽象意象均可使用。
- 不编造官方未确认角色、阵营结论、人物关系或具体剧情。
- 标题字应融入构图，作为主视觉的一部分，不是随意贴字。

## Agent 运行约束

`CoverPromptAgent` 应输出：

- `text_prompt = CONTROLLED_TITLE_TEXT: render only the exact song title "..."`
- `provider_options.text_policy = CONTROLLED_TITLE_TEXT`
- `provider_options.allowed_title = song_title`
- `visual_prompt` 明确只允许一个文本元素，即作品歌名。
- `negative_prompt` 明确禁止除作品歌名外的所有额外文字、署名、厂牌、版权、水印、二维码和 UI。

`QualityEvaluationAgent` 对 `COVER` gate 的判断：

- 若 prompt 正向要求假歌手、假版权、假厂牌、水印、二维码、UI 或随机小字，必须 `BLOCK` 或 `REWRITE`。
- 若 prompt 只允许作品歌名作为主标题，且没有额外文字风险，必须 `PASS`。
- 不做 OCR，不因为“标题字/歌名主标题”本身阻断。
- 不判断生成图像是否好看；视觉质量后续由真实样本人工抽查和公司侧审核承担。

## 当前边界

本规范只处理 prompt 层面的封面生成策略，不处理：

- 图像 OCR。
- 人工确认位。
- 多模态视觉评分。
- 公司审核系统接入。
- 视频模板改版。
